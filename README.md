# NITA
NITA-is a desktop based voice assistant that performs basic tasks like opening apps at the ease of a voice command, This project id embedded with reinforcement learning and other machine learning techniques to train the actual model, It also features an AI mode that connects you to an alternate Ai based chat that you can use for free conversations.

## The files provided in the repository does not define the actual structure of the application they must be arranged in a particular manner for them to work accurately.
